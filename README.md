# **This project is a books wishlisting web app using React over JS.**

**At the moment, User creation is Naive and Non persistant, change as you see fit**


# Local Setup instructions

1. Prerequisites
   Ensure you have Node.js (v18 or higher) installed on your machine.

2. Installation
   Clone the repository and install the dependencies required for the React/Vite environment:

   **Bash** <br>
   git clone <your-repo-url> <br>
   cd library-tracker <br>
   npm install

3. Running the App
   Start the development server:

   **Bash** <br>
   npm run dev <br>

   Open http://localhost:5173 in your browser.
